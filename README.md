## 🤔 Зачем это нужно?

Обычная установка RouterOS CHR на VPS — это десятки ручных шагов: скачать образ, смонтировать, прописать сеть, записать на диск, настроить firewall. Этот скрипт делает всё автоматически:

- ⚡ **За 3 минуты** VPS превращается в полноценный MikroTik-роутер
- 🔧 **Интерактивный мастер** — спрашивает только нужное, всё остальное определяет сам
- 🛡️ **Безопасно с первого запуска** — firewall, закрытые лишние сервисы, кастомные порты
- 🌐 **Полная пред-настройка** — сеть, DNS, NTP, DDNS, пользователи — всё готово до первой загрузки

## ✨ Возможности

### 🔍 Авто-определение окружения

| Что определяется | Описание |
|---|---|
| **Архитектура** | Проверяет x86_64, блокирует запуск на ARM и других |
| **Виртуализация** | KVM, Xen, VMware, Hyper-V — поддерживается. OpenVZ, LXC — блокируется с объяснением |
| **Режим загрузки** | UEFI или Legacy BIOS определяется автоматически |
| **Целевой диск** | Находит основной диск (`/dev/sda`, `/dev/vda`), предлагает как рекомендуемый |

---

### 📦 Что настраивается автоматически (без вопросов)

Следующее применяется при каждой установке без каких-либо вопросов:

- **NTP** — синхронизация времени через пул надёжных серверов:
  ```
  ntp0-3.ntp-servers.net, 0-3.pool.ntp.org, time.google.com
  ```
- **Web-прокси и SOCKS** — отключены (`/ip proxy`, `/ip socks`)
- **Лишние сервисы** — отключены: Telnet, FTP, WWW, API, API-SSL
- **MAC-server и Neighbor Discovery** — отключены (защита L2)
- **Канал обновлений** — задаётся при установке (stable / long-term / testing)

---

### 🌐 Настройка сети

- IP-адрес, маска, шлюз берутся из текущей системы — подтверди или введи вручную
- DNS по умолчанию: `8.8.8.8, 1.1.1.1` (Google + Cloudflare)
- Если IP уже настроен через DHCP — скрипт не упадёт, а пропустит с предупреждением в лог

---

### 🔐 Пользователи и безопасность

- **Пароль admin** — задаётся при установке, минимум 8 символов, вводится дважды для подтверждения
- **Резервный пользователь** — создаётся дополнительный аккаунт на случай блокировки admin
- **SSH-порт** — стандартный 22 или любой другой
- **Winbox-порт** — стандартный 8291 или любой другой

---

### 🔥 Firewall

Базовые правила применяются автоматически:

```
accept  — established/related соединения
drop    — invalid пакеты
accept  — ICMP (ping)
accept  — SSH (твой порт)
accept  — Winbox (твой порт)
drop    — всё остальное входящее
```

- **Авто-определение твоего IP** — текущий IP SSH-подключения автоматически добавляется как доверенный (никогда не заблокируется)
- **Дополнительный доверенный IP** — можно указать ещё один вручную

---

### ☁️ MikroTik IP Cloud (DDNS)

- Бесплатный динамический hostname от MikroTik: `xxxxxxxxxxxx.sn.mynetname.net`
- Всегда указывает на текущий IP роутера
- Удобно, если IP меняется или его трудно запомнить
- Включается опционально при установке

### 🔄 Версия RouterOS

- Выбор любой версии (например `7.16.1`, `7.23`) — скрипт скачивает с официального сервера MikroTik
- Выбор канала обновлений: `stable`, `long-term`, `testing`
- Образ скачивается с `https://download.mikrotik.com` — только официальный источник

## ⚡ Быстрый старт

### Установка за 1 команду

```bash
curl -fsSL https://raw.githubusercontent.com/avar-soft/mikrotik-chr-installer/main/install_chr.sh -o install_chr.sh \
  && chmod +x install_chr.sh \
  && sudo bash install_chr.sh
```

При запуске скрипт проведёт через 10 шагов:

1. Проверка совместимости системы
2. Выбор режима загрузки (UEFI / Legacy BIOS)
3. Выбор целевого диска
4. Настройка сети
5. Настройка пользователей и паролей
6. Выбор версии RouterOS
7. Дополнительные настройки (имя, DNS, таймзона, порты)
8. Проверка всех параметров перед записью
9. Загрузка образа и подготовка autorun.scr
10. Запись на диск и перезагрузка

**Весь процесс занимает ~3 минуты.**

## 🔧 Технические детали

### autorun.scr

При установке скрипт монтирует образ RouterOS и записывает в него файл `/rw/autorun.scr`, который выполняется при первой загрузке RouterOS. Файл содержит:

```routeros
:delay 30s
/user set admin password="..." group=full disabled=no
/ip address add address=1.2.3.4/24 interface=ether1
/ip route add dst-address=0.0.0.0/0 gateway=1.2.3.1
/ip dns set servers=8.8.8.8,1.1.1.1 allow-remote-requests=yes
/system clock set time-zone-name=Europe/Moscow
/system ntp client set enabled=yes
/system/ntp/client/set servers=ntp0.ntp-servers.net,...,time.google.com enabled=yes
/system ntp server set enabled=yes use-local-clock=yes
/ip proxy set enabled=no
/ip socks set enabled=no
/ip service set ssh port=2222
/ip service set winbox port=65000
# ... и т.д.
```

### Запись образа на диск

```bash
# Переводим ФС в read-only (защита от повреждения при записи)
echo u > /proc/sysrq-trigger

# Записываем образ
dd if=chr-7.x.x.img of=/dev/sda bs=4M oflag=sync

# Жёсткая перезагрузка
echo b > /proc/sysrq-trigger
```

## ❓ Частые вопросы

**Можно ли запустить на OpenVZ или LXC?**
Нет. RouterOS CHR требует полной виртуализации (KVM, Xen, VMware, Hyper-V). Скрипт проверит это на шаге 1 и остановится с объяснением.

**Какую версию RouterOS указывать?**
Рекомендуется `7.16.1` (stable). Можно указать любую доступную версию — образ скачается с официального сайта MikroTik.

**Потеряю ли я доступ к серверу?**
Да — текущая ОС полностью стирается. После перезагрузки сервер работает как роутер MikroTik. Управление через SSH или Winbox.

**Что делать если не могу подключиться после установки?**
Убедитесь что используете правильные порты SSH и Winbox, заданные при установке. Подождите 1–2 минуты после перезагрузки — autorun.scr выполняется с задержкой 30 секунд.

**Образ записался, но пароль не подходит?**
Попробуйте подключиться с **пустым паролем** — это дефолт RouterOS до выполнения autorun.scr. Если autorun выполнился успешно, в логах RouterOS (`/log print`) будет запись `CHR autorun: пароль admin установлен`.

## 🔐 Безопасность

- Пароль нигде не сохраняется в файловой системе хоста
- Лог установки отключается до перевода ФС в read-only
- Firewall активируется с первого запуска RouterOS
- Лишние сервисы (telnet, ftp, www, api) отключены по умолчанию
- MAC-server и Neighbor Discovery отключены (защита от L2-атак)
